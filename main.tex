\begin{abstract}
This template keeps only the typography that makes report-style preprints
easy to read on screen: a single A4 column with 2.2\,cm side margins,
XCharter text with matching newtxmath, a large left-aligned title, a compact
author block, and a full-width bold abstract. There is no logo, no copyright
line and no journal-specific metadata. Swap the document class back to
\texttt{article} or \texttt{sn-jnl} when a publisher requires its own style.
\end{abstract}
